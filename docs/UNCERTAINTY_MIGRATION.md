## Migration Policy Summary
1. All configuration properties missing direct test measurements will be flagged `confidence_level: LEGACY_ASSUMPTION`.
2. Existing values representing "reasonable looking" normal curves (like ±10% Cd) are frozen exactly as they appear in the previous YAML so that the nominal standard deviations generated by `monte_carlo_failure.py` remain constant across the switch.
3. The atmospheric multiplier will be abolished as requested ("Category D: Physically Inappropriate Model"). It double-counts uncertainty since `env_ensemble` actually fetches weather forecast uncertainty bounds explicitly via MAGI.
