# AI Assets

This directory contains resources, context, and skills for Artificial Intelligence assistants (like GitHub Copilot, Cursor, Gemini, Claude) interacting with the Antares Flight Dynamics repository.

* `context.md`: The core system prompt and architectural rules that any AI agent must follow when editing this repository.
* `skills/`: A directory containing specific scripts, custom instructions, or routines that extend the AI's capabilities for specialized tasks in this repository.
